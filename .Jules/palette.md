## 2024-11-08 - Adding accessibility to Vanilla JS dynamically generated components
**Learning:** In Vanilla JS projects generating HTML via template literals (like `RevisionPage.js`), standard static accessibility linters often miss icon-only buttons created inside JavaScript strings. Furthermore, UI elements like `mj-wiz-back` and `mj-modal-close` require careful localization context when determining their `aria-label`s, such as referencing a boolean `fr` flag or dynamically determining RTL directionality (e.g., in RTL, "›" indicates "الشهر السابق" - Previous Month, while "‹" is "الشهر التالي" - Next Month).
**Action:** When working on pure string-based HTML template generation, manually search for `<button` patterns inside `.js` files. Specifically look for controls containing only symbols or emoji (like `✕`, `‹`, `›`, `⊖`) and explicitly inject dynamic `aria-label` and `title` attributes that mirror the interface's current localization logic (e.g., using ternary operators like `${fr ? 'Retour' : 'رجوع'}`).
