## 2024-05-18 - Native Form Submission for Better UX
**Learning:** Using native `<form onsubmit="...">` with `<button type="submit">` instead of a standalone `<button type="button" onclick="...">` restores the ability to submit forms using the 'Enter' key. This significantly improves keyboard accessibility and overall user flow.
**Action:** Always prefer native form submission patterns over standalone click handlers on buttons within forms.
